Your VRChat messages,
on a tiny desk pager.

Install over USB from Chrome or Edge. No Arduino IDE required.

01

Flash the pager

Connect the CYD with a data-capable USB cable, then choose its serial port. The first install erases saved settings.

Use desktop Chrome or Edge with Web Serial enabled.
02

Join Wi-Fi

1

Find the setup network

After flashing, connect your phone or computer to CYD-Pager-xxxx.

2

Open setup

The portal should appear. If it does not, visit 192.168.4.1.

3

Enter details

Save your 2.4 GHz Wi-Fi credentials and OSC port, normally 9001.

03

Route OSC

VRChat emits OSC to localhost. Use an OSC router on the VRChat PC to forward UDP port 9001 to the IP shown along the bottom of the pager. Forward /chatbox/input, or send a string directly to /cyd/message.

HELP

Troubleshooting

No serial port appears

Use a USB data cable, install the board's CH340 driver if Windows shows an unknown device, close Arduino Serial Monitor, and reconnect.

Install cannot connect

Hold BOOT, click install, release BOOT when “Connecting” appears. Some boards need a quick press of EN/RST.

Setup network does not appear

Hold BOOT while resetting the board. Keep holding until SETUP MODE appears.

Pager is online but receives nothing

Confirm the target IP and UDP port in the OSC router, allow UDP through the PC firewall, and ensure both devices are on the same LAN. Guest Wi-Fi often blocks device-to-device traffic.

Wrong Wi-Fi details

Hold BOOT for five seconds while the pager is running. It clears saved settings and restarts the setup portal.
