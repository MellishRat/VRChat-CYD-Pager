ESP32-2432S028R

Your standalone
VRChat pager.

Wi-Fi connected, authenticated, and logged directly into VRChat. No companion app required.

01

Flash the pager

Connect the CYD with a data-capable USB cable, then put it into firmware-download mode:

  1. Press and hold BOOT.
  2. While holding BOOT, press and release RESET/EN.
  3. Keep holding BOOT, choose the appropriate installer below, and select the CYD serial port.
  4. Release BOOT once the installer begins erasing or writing the firmware.

Standard display

Use this first for most CYD boards.

Use desktop Chrome or Edge with Web Serial enabled.

Inverted-colour display fix

If the standard firmware makes the screen look pale, negative, or colour-inverted, install this version instead.

Use desktop Chrome or Edge with Web Serial enabled.

Installation erases previously saved settings, including Wi-Fi and VRChat login details.

02

Set up on the touchscreen

1

Select Wi-Fi

The pager scans nearby networks. Tap your 2.4 GHz Wi-Fi name and enter its password on screen.

2

Sign in to VRChat

Enter your VRChat username and password using the touchscreen keyboard.

3

Complete verification

If requested, enter your authenticator or email OTP. The resulting session is saved on the pager.

03

Receive notifications directly

The pager connects directly to the VRChat API and Pipeline WebSocket. Invites, friend events, boops, group activity, and system alerts appear automatically—no OSC router or companion app is required.

HELP

Troubleshooting

No serial port appears

Use a USB data cable, install the board's CH340 driver if Windows shows an unknown device, close Arduino Serial Monitor, and reconnect.

Install cannot connect

Hold BOOT, press and release RESET/EN, and continue holding BOOT while selecting the serial port. Release BOOT only after the installer begins erasing or writing the firmware.

The display colours are inverted

Return to the installer above and choose Install inverted-colour fix. Visually identical CYD boards can contain LCD panels that require opposite inversion settings.

My Wi-Fi network is missing

The ESP32 supports 2.4 GHz Wi-Fi. Refresh the on-device scan and ensure the network broadcasts a compatible 2.4 GHz signal.

VRChat asks for verification

Enter the current code from your authenticator or VRChat verification email using the on-screen keypad.

Notifications stop updating

Open Advanced and use Reconnect. Confirm Wi-Fi is available; the pager also retries the Pipeline quietly in the background.
